## 📌 1. Descripción del proyecto

**SuperOfertas Ecuador — Evaluación y Rediseño UX** es un proyecto académico orientado al análisis, evaluación y mejora de la experiencia de usuario de una interfaz de comercio electrónico, específicamente la pantalla **"Revisa la dirección (Mapa)"**, correspondiente al proceso de compra.

El proyecto busca identificar problemas de usabilidad mediante el análisis de los momentos de interacción, la evaluación emocional de usuarios y la identificación de dificultades durante la navegación.

A partir de los resultados obtenidos, se plantea el rediseño de la interfaz en **Figma**, aplicando principios de Interacción Humano-Computador para mejorar la organización visual, la claridad de los controles, la prevención de errores y la experiencia general del usuario.

Finalmente, se realizará una nueva prueba con usuarios para comparar los resultados antes y después del rediseño, documentando los hallazgos y las mejoras identificadas.

## 🎯 2. Objetivos

### Objetivo general

Evaluar y rediseñar la interfaz **"Revisa la dirección (Mapa)"** de SuperOfertas Ecuador mediante principios de Interacción Humano-Computador, con el propósito de identificar problemas de usabilidad, analizar la experiencia emocional de los usuarios y proponer mejoras que faciliten la interacción durante el proceso de compra.

### Objetivos específicos

1. **Identificar** cinco momentos de interacción durante el proceso de revisión de la dirección de entrega, analizando las acciones, dificultades y emociones experimentadas por los usuarios.

2. **Evaluar** la experiencia de al menos tres usuarios mediante pruebas de interacción, construyendo una curva emocional y una matriz UX que relacionen momentos, emociones, evidencias y propuestas de mejora.

3. **Rediseñar y verificar** la interfaz mediante un prototipo interactivo en Figma, realizando una comparación antes/después y una nueva prueba de usuario para determinar la efectividad de las mejoras.

## 🔎 3. Problema identificado

La interfaz original de SuperOfertas Ecuador presenta diferentes características visuales y funcionales que pueden dificultar la interacción del usuario durante la revisión de su dirección de entrega.

| Problema | Descripción | Posible consecuencia |
|---|---|---|
| **Sobrecarga visual** | Uso excesivo de colores intensos como amarillo, rojo y verde. | Dificultad para identificar la información más importante. |
| **Jerarquía visual deficiente** | Los títulos, enlaces, botones y mensajes compiten visualmente. | Mayor esfuerzo para comprender la pantalla. |
| **Controles poco claros** | Las opciones de guardar, volver y omitir no presentan una jerarquía de acciones consistente. | Confusión al decidir cómo continuar. |
| **Mapa poco comprensible** | La representación del mapa y los controles de ubicación presentan información limitada. | Dificultad para verificar la dirección. |
| **Presión durante la interacción** | La oferta y el temporizador compiten por la atención del usuario. | Posible sensación de urgencia y aumento de errores. |
| **Inconsistencia visual** | Diferencias en tamaños, estilos y alineación de los elementos. | Menor claridad y consistencia de navegación. |

Estos problemas constituyen hipótesis iniciales de evaluación que deberán contrastarse mediante pruebas con usuarios.

| **Matriz UX** | Relación entre momento, emoción, evidencia y propuesta de mejora. |

## 🔄 5. Metodología de trabajo

El proyecto se desarrolla mediante seis actividades principales.

### Fase 1. Identificación de momentos de interacción

Se analizará el recorrido del usuario en la pantalla de revisión de dirección, identificando **cinco momentos de interacción** distribuidos entre las etapas antes, durante y después de la acción principal.

### Fase 2. Evaluación emocional inicial

Se realizará una prueba con **al menos tres usuarios**, registrando sus experiencias durante los cinco momentos identificados.

Se utilizará una escala emocional de referencia:

| Valor | Interpretación |
|:---:|---|
| **+2** | Muy satisfecho |
| **+1** | Satisfecho |
| **0** | Neutral |
| **-1** | Frustrado |
| **-2** | Muy frustrado |

Los resultados permitirán elaborar la **curva emocional inicial** e identificar momentos críticos.

### Fase 3. Construcción de la matriz UX

Se elaborará una matriz que relacione los momentos de interacción con las emociones observadas, las evidencias recopiladas y las propuestas de mejora.

### Fase 4. Rediseño en Figma

Se desarrollará una propuesta visual que responda a los problemas identificados, priorizando la claridad de la información, la organización del mapa y la comprensión de las acciones disponibles.

### Fase 5. Verificación de mejoras

Se realizará una nueva prueba con usuarios utilizando tareas equivalentes a las de la evaluación inicial.

Se compararán las emociones, dificultades y resultados registrados antes y después del rediseño.

### Fase 6. Documentación y entrega

Se consolidarán las evidencias, curvas emocionales, matriz UX, capturas del prototipo, conclusiones y enlaces en un documento PDF para su entrega en Moodle.
